# NAFRI AI - Premium Agentic AI Workflow Assistant

ChatGPT / Meta AI madhiri oru Premium AI Agent. Naan build panna enoda own AI!

## Features
- Chat with Gemini Brain
- Memory / Chat History - Unakku nyabagam irukkum
- Live Web Search - Today News, Gold Price, Live Score
- Image Generation - Photo uruvakkum
- File Upload & Summary - File padichu sollum
- Time Tool & Calculator Tool
- Premium Chat UI with Sidebar + History

## Tech Stack
Python, FastAPI, Gemini AI, HTML, CSS, JavaScript

## How to Run
1. pip install -r requirements.txt
2. Create .env file with GEMINI_API_KEY=your_key
3. uvicorn backend.main:app --reload
4. Open frontend/index.html
